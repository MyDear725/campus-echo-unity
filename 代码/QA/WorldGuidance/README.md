# 路线指引与昼夜灯光 · 2026-10-20

修改原Unity主项目，沿用唯一游戏时钟、现有学期手册及真实场景。无提交或推送。

## 已实现

- 地面绿色路线：室外按原校园移动碰撞图寻路，避开建筑、水域和其他已登记障碍；室内基于实际地面与碰撞体寻路，门洞、走廊和楼梯使用实际位置。
- 追踪目标后先引到对应建筑入口，进入后继续引到实际交互点；去别的楼先引到本楼出口。宿舍高层先引到下楼交互点，寝室内先引到房门。
- 学期手册 `K → 生活与设置 → 路线指引线` 开启/关闭，另有取消追踪。关线保留文字方向提示。显示偏好独立于学期进度保存，重置不强制改回；当前追踪目标随学期进度存档。
- 使用同一游戏时钟驱动太阳、天空、环境色、雾与校园材质。05:00–07:00逐渐天亮，16:30–19:30逐渐变暗。
- 每日18:00路灯开启，次日06:00关闭。包括原庭院灯头、沿实际校园道路补充的路灯及暖光地面效果。附近最多8盏实时光源，保持开灯成本受控。
- 室内保留原有照明可读性；窗外背景随时间变暗，返回室外后同步当天时刻。读档、休息、快进、每日/学期重置均按恢复后的时间更新。
- 夜间覆盖原先固定亮度的户外地面、宿舍、教学楼、图书馆与玻璃材质。通过外景标记避免将共用材质的室内整体压黑。
