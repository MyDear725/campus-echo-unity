# 校园环境最终检查 · 2026-10-22

基于 GitHub `main` 的 `d14df57b`，使用本机 Unity 6000.3.26f1 检查现有场景；没有重新生成校园或改动建筑的位置和内部玩法。

## 已完成的修复

- 将信息楼、篮球场的 25 个镜像 BoxCollider 转换到正尺度的物理层级；转换前后世界包围盒误差不超过 3 mm。可见模型的位置、方向和尺寸不变。
- 食堂南侧路口一盏路灯从地图坐标 `(213,39)` 移到 `(214.2,42)`，灯杆、底座、灯臂、灯罩及碰撞同步移动，避开两条交叉道路。
- 北庭院与一、二、四、五、六、七舍及食堂的 9 条道路，统一将导航起止点对齐实际入口外侧的 E 交互位置。修复原来终点落在实体外墙或起点贴入外挑立面的情况；通往门廊的可见铺装保留。
- 图书馆 87 处标牌统一使用高分辨率字体，校准偏小文字；展板说明文字移到标牌外表面，避免嵌在板内。图书馆原有 61,477 个序列化对象 ID 全部保留。
- 加大地图、日期与交互提示的文字；长提示根据内容换行并扩展背景高度。HUD 使用与剧情界面协调的圆角底板，缓存日期文字样式，减少重复分配。
- 地图关闭按钮加宽，修复小窗口下“关闭”换行；方向线和标注连线不再在缩放裁剪区域内旋转 GUI 矩阵，消除地图外错位的蓝色短线。
- 隐藏食堂三楼楼梯边 6 组完全重叠的多余栏杆立柱渲染，每处保留一根可见立柱及安全碰撞。
- 在本机复现两次 `D3D12Core.dll` 退出崩溃后，Windows 默认改用 Direct3D 11。复测教学楼退出正常，玻璃、水面与室内抗锯齿保留。

RTX 4060 Laptop / Ryzen 7 7840H，1440×900，Direct3D 11。固定视角取消帧率上限采样，入口、教学区、桥面、图书馆和食堂平均帧时间约 **5.88–9.18 ms**，相应约 109–170 FPS；正常游戏仍限制到 120 FPS。详见 `performance-windows.csv`。渲染线程计时器在当前接口下不可用，CSV 的该列 0 不代表没有渲染开销。

这些是本机固定视角的抽样与现有场景的通行检查，不是其他设备的性能保证，也不等于完整学期剧情的连续人工通关。

## 复查方法

先用 Unity 菜单 `Campus / Build Windows Demo` 编译当前已保存的场景，然后在项目根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File QA/FinalAudit/run-windows-checks.ps1
```

脚本使用隔离的测试存档；任一检查失败会返回错误。`CampusFinalAudit.Audit` 只读取现有场景，`CampusFinalPolish.ApplyAndBuild` 可重复应用本轮修复并构建，均不调用原始校园生成器。
