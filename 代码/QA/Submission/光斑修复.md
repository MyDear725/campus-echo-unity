# 室外白色光斑修复

2026-10-23，用户确认异常表现为白色光球或亮斑，而不是地面重叠。先前关于界面状态和垂直同步的排查不作为本问题的根因；相关界面代码与同步设置未作修改。

实际 Windows 玩家窗口的同机位对比确认：室外后期 Bloom 强度为 0.12 时出现悬浮白色光球，强度设为 0 后消失。因此关闭 `CampusEnvironmentPresentation` 的室外 Bloom，保留原日光、色调映射、夜间灯具与点光源；室内独立后期配置不受影响。

使用 `CampusGlareQA`（启动参数 `-frameStabilityQA`）在独立测试存档中验证，不能以最小化或隐藏窗口的黑图作为通过证据。检查包括同机位开启/关闭 Bloom、相机转向、桥头白天视角及 19:00 夜间灯光。截图位于本地 `Builds/Windows/QA/FrameStability/glare/`，不会上传。

本机同机位对比减少 14,804 个异常扩散的高亮像素，新增高亮像素为 0；实际查看截图确认光球消失，夜间路灯仍点亮。Windows 构建及上述图形检查通过。本次不声称修复了所有其他类型的闪烁，也未重复性能基准。
