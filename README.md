# 风起 · 校园

以大学校园生活为主题的第三人称 3D 校园探索游戏。你将以新生的身份走进校园，在迎新、上课、自习与日常生活中，体验自己的第一个大学学期。

## 启动游戏

**Windows：双击仓库根目录的「启动游戏.cmd」。**

- 本机已有运行包时，脚本会启动游戏；源码更新后会先重新构建。
- 首次运行源码需要安装并激活 **Unity 6.3 LTS（6000.3.26f1）**。脚本会查找已安装的 Unity，完成构建后启动；首次导入资源可能需要较长时间。
- 请先完整下载或克隆整个仓库，再启动；只下载启动脚本无法运行游戏。

也可以在 Unity Hub 中添加「代码」文件夹，打开 `Assets/Scenes/CampusLiving.unity` 后点击播放。macOS 可通过 Unity 编辑器游玩，已有 Mac 运行包时可使用「代码/启动游戏.command」。

## 核心内容

- **自由探索校园**：穿行教学区与生活区，游览双湖、林荫道路、图书馆、体育馆和有顶学苑桥。
- **进入建筑探索**：靠近入口按 E，进入教学楼、图书馆、食堂与宿舍等空间。教学楼与体育馆等建筑可以沿实体楼梯上下楼。
- **迎新与校园故事**：跟随学姐小岚熟悉校园，通过对话选择、课程与日常活动推进自己的新生生活。
- **体验一个学期**：查看课表、参加课程、完成作业、预约图书馆座位并自习，安排用餐、休息与生活费。
- **感受时间变化**：游戏时间推动日程，校园随时间呈现昼夜与灯光变化；可以追踪目标并显示路线指引。

## 操作与玩法

| 操作 | 按键 |
| --- | --- |
| 移动 | W / A / S / D |
| 转动视角 | 移动鼠标 |
| 调整镜头远近 | 鼠标滚轮 |
| 奔跑 / 跳跃 | Shift / 空格 |
| 交互、进入或离开建筑 | E |
| 校园地图 | M |
| 手机、预约等功能 | P |
| 课表与学期手册 | K |
| 当前指引 / 日程 | J |
| 暂停、返回或释放鼠标 | ESC |

初次进入时选择角色，跟随迎新指引完成校园报到。之后可以自由探索，或打开学期手册查看当天课程和目标。

图书馆自习需要先用手机预约座位，到对应座位附近按 E 落座，再选择科目和学习时长。食堂可进行点餐、取餐、用餐与归还餐盘。宿舍提供休息和日常生活入口。

日常探索时，现实 1 分钟约对应游戏 5 分钟；打开对话、手机、手册或暂停时，时间停止。学习、上课与休息等活动会按对应时长推进游戏时间。
