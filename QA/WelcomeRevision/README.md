# 小岚与宿舍楼梯修正

用户要求：暂缓原人物贴图缺失；修复小岚移动无身体摆动、身高与主角一致，以及下行楼梯仍为上行造型的问题。所有修改仅保留在本地，未提交或推送 GitHub。

## 修改

- 小岚运行时创建 UMA 时，首次切换种族会读取未初始化的 slotDataList，导致异常并回退旧模型。初始化运行时空数组后，再使用项目已有 Sheila 预设生成角色。
- UMA 生成/更新完成后绑定已有 Locomotion 控制器，按实际水平位移驱动行走和站立，避免传送触发跑步；关闭根运动，保持剧情代码负责移动。
- 根据当前主角和小岚的 Humanoid 骨架比例匹配身高，避免用动画中变化的渲染边界逐帧缩放。UMA 默认胶囊高度不是可靠的人物身高。
- 上下行分别采用正、负台阶高度，移开覆盖下行楼梯的地板；平台留足角色胶囊通行宽度，扶手随坡度升降。一楼封住下行入口，六楼封住上行入口。
- 本轮追加楼梯踏步下的连续隐形碰撞斜面，避免胶囊从分离的踏步间隙落入楼梯井。
- 新增走廊标语和可按 E 进出的共用寝室模型：四套上床下桌、左侧围合厕所、右侧洗手台和阳台中心花园景观画面。

## 验证方法

可复现入口：Unity 6000.3.26f1，执行 WelcomeIntegrationRunner.Run，带 -welcomeIntegrationQA -welcomeRevisionQA。测试保留并恢复原剧情存档。

使用原男女 UMA 预设，烘焙真实站立网格比较身高（容差 3.5cm）；启用真实剧情跟随代码，检查实际位移、手臂和腿部骨骼角度变化、动画状态及对话/暂停时回到站立。随后通过原 E 分派和实际角色胶囊完成一至六楼往返，检查两端上/下行台阶碰撞表面、下行楼梯无地板覆盖、房号和终点封挡。

guide-walk-*.png 来自真实 Unity 相机连续采样；Male-height.png、Female-height.png 是原男女主角与小岚的同场景对比；stairs-floor-2.png、stairs-floor-6.png 是实际 Unity 楼梯截图。楼梯截图使用原相机的专用检查机位，行走录制使用跟随机位，均不代表玩家默认视角。

贴图问题按用户要求暂缓。未验证 Windows，也未在本轮验证完整食堂/图书馆剧情。早期失败记录保留在 attempt-* 中；以根目录 result.txt 为本轮最终结果。

此前 102 项检查覆盖小岚动画、身高及早期楼梯版，不覆盖本轮寝室模型和连续斜面。后来本轮实体胶囊测试发现楼梯仍有穿落，已追加连续斜面；其后在此 Mac 上的 Unity 批处理因 UMA 编辑器窗口报“没有可用图形设备”而中断，尚未完成斜面后的双向实走、寝室出入或截图验证。当前没有 `room-101-layout.png`。因此本版是待验证的本地预览，未上传 GitHub。


## 2026-10-20 阳台与寝室碰撞补丁

基于用户提供的实际游戏截图，发现房间根对象保持 inactive，且房间进入状态仅激活父对象；现已在切换玩家位置前激活房间根，并在 QA 中检查真实 renderer 是否启用。入口原先由实心门板/门框挡住并缺少安全外侧地面，已改为开放门洞、门柱与门楣，并补入口落脚平台和边界墙。用户新截图进一步复现室内装饰门板挡住左侧厕所路线；现将该门板改为无碰撞展示，并将厕所入口从约 0.84m 加宽至约 1.24m。新增角色实际通过隔断入口的 QA 路线。阳台景观改用 `Assets/Resources/Onboarding/central-garden.jpg`；图片后方增加不可见碰撞墙，两侧封闭，栏杆间距缩小。

本补丁的 Unity Play Mode 验证尚未完成：该 Mac 上以批处理方式启动时，UMA 自动欢迎窗口因没有图形设备而报错。新增 QA 会验证阳台碰撞墙及角色胶囊不能穿过照片平面，但在测试实际通过前不将本补丁标记为运行时已验证。未推送 GitHub。

## 2026-10-20 门、HUD 与家具优化

按最新截图继续调整：进入寝室后先把人物放到门内安全位置，再关闭寝室门；返回走廊时先开寝室门，角色离开后再关闭走廊门。门轴带实际门板碰撞体，门扇朝入口右侧收拢，给左侧厕所入口留出通路；QA 增加关门状态、厕所通道胶囊实走及门口返回提示检查。四套上床下桌整体加宽加深，补床垫、被褥、枕头、床头板、护栏、床梯、抽屉和带靠背座椅，尽量把碰撞体限制在家具本体。左上角状态框依据当前屏幕宽高缩放，并按文本实际换行高度增加面板高度。

实机回归中还发现下行坡面方向被反转，导致角色沿下行楼梯反而升高；现已统一上下楼梯斜坡、侧梁的世界倾斜方向，同时把下行支撑斜坡中心高度改为负值。原回归曾在一楼被正确启用的下行挡板挡住，现改在二楼实走上下坡，再返回一楼检查寝室。
