# 八处校园道路景观

## 布局与主要假设

- 沿用 `CampusLiving` 中已有地图、建筑坐标与入口系统，北为地图 -Z、东为 +X；游戏显示层的镜像转换仍由 `CampusGame.MapToWorld` 统一处理。没有把参考图作为立面、地面或天空贴图。
- 采用约 1 Unity 单位 = 1 米的游戏尺度。道路宽度沿用现有规划；新增入口步行带宽 3.2 m，运动带宽 2.1 m。座面约 0.48 m、桌面约 0.76 m、护栏约 1.1 m、普通庭院灯约 4.5 m。参考图不提供实测尺寸，这些尺寸和背面、转角处理属于概念设计。
- 教学区位于学府大街西侧，生活区在东侧；A、弧形 B、C、图书馆、体育馆、食堂和宿舍复用现有外观与室内接口。没有为配合参考图而移动这些建筑，也不重新制作室内。
- 七舍继续按**北低南高，北门 LG、南门 1F**：设计高差 2.85 m。沿生活区已有坡道采样地形高度。
- 学苑桥桥面约 6.5 m，两侧直线楼梯及封顶、挡风玻璃保留，东侧下桥直对食堂。新增两侧桥底纵梁及楼梯承托，不占桥下车行走廊。桥下与桥面使用独立碰撞结构。
- 入口步行路线沿南入口、信息楼外侧至书韵广场组织；原有车行路保留。参考图中的绿色道路仅视为连接标识，三维路面采用灰色铺装。
- 湖岸保持现有两处水体轮廓与项目兼容的动态水面材质；有条件的路侧补充护栏、低位灯、岸边斜面和木质停留平台。观景平台位于西侧岸路旁，未改变湖体面积。
- 憩苑入口、背面以及没有资料的连接部位采用与现有建筑一致的简约补全。自行车、垃圾收集点是环境道具，不接入新的人群或交通 AI。

## 八个节点

| 节点 | 项目位置与实现 |
| --- | --- |
| 01 入口林荫主路 | 南入口西侧新增连续步行带，暖灰铺装、深色边带、树阵与侧边座椅，保留原校园车行路线。 |
| 02 教学楼间步行道 | 沿 ABC 内庭通行轴完善铺装、树池、灯具与侧边阅读设施；主要门口留空。 |
| 03 图书馆阅读步道 | 书韵广场及北侧连接路、弧形铺装边带、两侧阅读桌椅和绿化；中央保持集散用途。 |
| 04 环湖景观步道 | 思源湖及涌泉湖环路使用细骨料质感，补充石质岸坡、木扶手金属栏杆、低灯与观景台。 |
| 05 学苑桥桥头 | 延续直线通行、独立高程与实体台阶，增加桥底承托、两侧花坛和停留设施。 |
| 06 宿舍林荫路 | 生活区改为小尺度暖灰步行铺装，沿西坡道和庭院增加树荫、座椅和独立自行车位。 |
| 07 食堂前步行街 | 西门前扩展灰色集散空间，入口轴线不布设施；桌椅、树木、自行车和垃圾收集点在两侧。 |
| 08 体育馆运动步道 | 体育馆南侧灰色步行路与低饱和砖红运动带并行，补充座椅、路灯和饮水设施，区别于正式田径场。 |

## 后续编辑

- 入口和道路坐标：`Assets/Scripts/CampusPlanRoadNetwork.cs`、`Assets/Editor/CampusPlanBuilder.cs` 中的 `NewRoads`。
- 八节点配置：`Assets/Editor/CampusRoadScenery.cs`。家具、种植池及树木模块：`CampusRoadSceneryModules.cs`。
- 乔木为有分枝和折叠叶片的三维结构，三个共享变体，每个具有三级 LOD。材质和模型放在 `Assets/CampusPlanRevision/RoadScenery` 与 `Materials` 中。
- 铺装材质采用世界空间米制采样，区分矩形砖、小砖、骨料、石材、木材、金属和叶片，不依赖建筑 UV 拉伸。
- 编辑器菜单 `Campus > Apply campus plan and covered bridge` 重建室外布局；调用 `CampusPlanBuilder.GenerateAndBuild` 重建并打包。生成前先保存手工场景修改，生成组内的手工修改会被重建覆盖。
- `-campusPlanQA` 自动检查所有登记道路、八节点连续步行、双向上桥下桥、桥下通行、七舍两入口和室内实走楼梯，并输出八处视角截图。`-entranceQA` 检查所有建筑的进出回程。

本方案用于校园游戏环境设计，不构成测绘级复原；树种、景观设施和没有精确资料的连接区域为合理补全。
