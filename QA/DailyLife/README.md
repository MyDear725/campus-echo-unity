## 操作验证的明确限制

最终63项检查调用**界面按钮实际使用的预览、确认与取消回调**，验证界面状态、条件重检和交易结果；没有把回调调用描述成真实鼠标点击。

编辑器中的合成鼠标事件在滚动区域被忽略；桌面工具读取 Unity 编辑器和独立游戏窗口多次超时。因此，原生鼠标命中、滚动后点击和完整键鼠游玩仍需人工复核。此前的失败输入试验保留在 `attempt-input/`。既有 HUD 在右上角覆盖手册一部分的显示问题本轮沿用；本轮没有进行全局 HUD 重排。

后续状态：上述手册遮挡已在[全剧情复查](../StoryJourney/README.md)中修复并重新渲染验证；原生鼠标验证的限制仍保留。该复查还在最终应用上再次通过63项每日事项/旧存档回归。

Windows 未运行，本轮也不宣称长期性能与内存稳定性已验证。独立进程退出时仍报告之前环境验证已出现的两项 Persistent 原生分配，未做归因。

## 复现入口

编辑器逻辑：`WelcomeIntegrationRunner.Run`，参数 `-dailyLifeQA`。可视 Game View：`DailyLifeReview.Run`，同一参数，不使用批处理模式。

独立游戏：参数 `-dailyLifeQA -dailyLifeOutput <绝对输出目录>`，以可见窗口运行。测试独立设置 `DailyLifeQA20261022.` 前缀，保留玩家的真实学期、余额、物品和角色选择。显示尺寸按测试临时切换。

构建入口为原有 `MacPlayerBuilder.BuildFromCommandLine`；最终成功构建14个场景、约2.0GB，仍由原有启动脚本打开。构建与独立运行日志分别是 `Logs/daily-life-content-final-build.log`、`Logs/daily-life-verified-player.log`。
