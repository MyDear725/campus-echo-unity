# 图书馆预约与学科学习修复 · 2026-10-22

## 已修复

- 手机平面图按圆厅A、阅览B分区展示，普通座位标记缩小、所选座位使用白框与黄色编号；显示明确的已选编号、确认预约按钮和状态图例。点击按最近座位中心判定，避免相邻热区先后次序造成误选。
- 在座位点击“开始学习”打开独立自习面板，三门科目各有30/60/90分钟按钮、精力成本、当前掌握度、游戏时刻和学习完成结果；不会与原座位上的起身/释放按钮同时响应。
- 手机、自习面板和学期手册优先获得输入。一次点击打开面板后，停止向其他面板继续分发这一输入。
- 落座即标记预约使用中；针对学习不会清除占用状态。坐着时拒绝更换到其他座位，重复确认当前座位不改变占用状态。学习事务核对预约编号与实际所坐座位一致。
- 起身保留预约并取消占用，只有主动结束才释放预约。强制起身同时关闭自习面板和鼠标锁，避免读档/重置留下悬空面板。
- 学习完成明确显示时刻、精力和掌握度的前后值。普通HUD时钟不再遮住自习面板的返回按钮；统一钱包仍显示。
