# 校园环境画质 · 2026-10-22

本轮是现有校园的渲染细化，方向为清透、温暖的校园日常。保留已有建筑布局、道路、碰撞和交互。

## 已实施

- 统一室外天空补光与地面反弹光，减轻原先固定高亮补光造成的平面感；宿舍外墙的调整仅在室外标记启用时生效。
- 草地使用以米为单位的多尺度颜色变化与近景细节；远处衰减高频纹理，减少闪烁。
- 树叶增加轻微逆光透光感；沿用已有植物模型与动画。
- 水面增加视角反射、随时间变化的微波、天空色与程序云色反射、受阴影控制的太阳高光。**不是实时场景倒影**，不会倒映岸边建筑。
- 天空增加云层明暗与太阳光晕，黄昏的天顶和地平线颜色随原有游戏时钟变化。
- 室外增加独立的 ACES 色调映射、轻微调色和克制的泛光。进入建筑后权重归零，返回室外恢复；不修改既有室内配置。
- 抗锯齿由 2× 提至 4×；主光阴影由 2048 提至 4096，使用四级阴影和中档软阴影，距离 100 米。保留现有性能构建入口，调用 `CampusPerformanceBuild.Optimize` 可恢复较低开销的设置。

## 查看与复现

`QA/EnvironmentQuality/before-*.png` 与 `after-*.png` 为真实 Unity 编辑器同机位渲染，1600×900，统一上午十点的主光方向与强度。不是概念图，也不是连续游玩截图；不含角色与 HUD。

编辑器方法 `CampusEnvironmentReview.Baseline` 拍摄当前设置，`CampusEnvironmentReview.Improved` 应用本轮渲染质量并拍摄。本轮修改后再次调用 Baseline 得到的是当前版本，不能重建旧版材质效果；已保留修改前图片。

`CampusEnvironmentReview.Validate` 先输出三个场景视角，再进入真实 CampusLiving 执行已有室外引导与昼夜回归。需要同时传入 `-semesterQA -campusWorldQA -environmentQualityQA`，隔离游戏进度并将结果写入本目录的 `runtime/`，不覆盖之前的回归证据。

## 范围和后续

本轮未替换树木、灌木、建筑或角色模型。原有低细节灌木轮廓、重复树冠和简单地形仍然可见。下一步最有价值的是制作少量高质量植物资产，先用于玩家经常经过的主路、湖岸与宿舍入口，再处理远景层次；仅继续增加滤镜无法解决模型轮廓问题。

4× 抗锯齿和更高阴影分辨率增加显存及 GPU 开销。编辑器画面不能证明 Windows 性能；Windows 实机及不同显卡仍需验证。

## 交付验证

真实编辑器 Play Mode 与新打包的独立 Mac 游戏各通过 49 项昼夜、路径、实际建筑进出和室外后期生命周期检查。完整 Mac 构建成功，14 个场景，约 2.0 GB，已更新原有启动脚本对应的应用。测试结果与范围见 `QA/EnvironmentQuality/README.md`。
